## 🧪 Technical & Computational Stack

Rather than treating computational tools as black boxes or wet-lab assays in isolation, my toolkit integrates both domains:

| Scientific Domain | Experimental Methodologies | Computational Stack & Tools |
|---|---|---|
| **In Silico Drug Discovery** | Target receptor identification, binding pocket analysis, structure cleanup | `AutoDock Vina`, `RDKit`, `PyMOL`, `Biopython`, `PDB Database` |
| **Analytical Metabolomics** | GC-MS chromatography, FT-IR spectroscopy, solvent extractions (Soxhlet, ultrasonic) | Kovats retention index calculations, NIST deconvolution, `GNPS` |
| **Scientific Computing** | Hypothesis testing, One-way / Two-way ANOVA, Tukey HSD, growth kinetics | `Python 3.10+`, `NumPy`, `Pandas`, `SciPy`, `Scikit-Learn (PCA)`, `Matplotlib`, `Jupyter` |
| **Plant Biotechnology** | Somatic embryogenesis, multiple shoot induction, aseptic micropropagation | MS media salt calculation, growth curve modeling, hormone dilution math |
| **Secondary Elicitation** | Jasmonic acid, Salicylic acid, and NaCl treatment in cell suspension cultures | Time-series metabolite accumulation statistics, fold-change analysis |
| **Controlled Agriculture** | Nutrient Film Technique (NFT) hydroponics, nutrient dosing, microclimate monitoring | EC/pH kinetic modeling, statistical yield optimization |
